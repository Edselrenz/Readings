If you are unfamiliar on using github, this is a step by step on how to download and setup this readings library.
1. Go to the top of the github page and you will find a green button labeled "<> Code".
2. Click on the "<> Code" button and you will see a Download Zip, go ahead and download it.
3. After downloading, unzip it inside a new folder, name it whatever you want.
4. After unzipping, find the tracker.html inside the folder.
5. That's it, you now have access to this readings library.
